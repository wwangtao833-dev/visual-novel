JAST（日本） 作品专题

本专题的 JAST 是 1985—2001 年间活动的日本株式会社ジャスト。旗下品牌的实际署名保留在版本中，筛选归档为“JAST（日本）”；JAST USA／现代 JAST 国际发行方单独保留。2001 年 Purple software 承接后的系列作品仅作沿革关联。 早期クレスト（Crest／Clest）依据机种馆录的 JAST 新品牌说明归档，保留版本实际署名。

1985—2001作品首发跨度

以发行《天使们的午后》的日本旧 JAST 为主体，整理本社、Crest、Tiare、早期 Purple、Angel Hearts 与 pride 的历史目录。现有 32 部四类作品与 7 部跨类型关联作品；2026-10-08 追加三部图文菜单指令作品，已有作品与版本保留原样。

列出有来源的主要初版、移植、重制与合集记录，不宣称穷尽所有地区和再版。发售月份冲突时只记年份；有年份冲突的 III 番外篇保留异文。部分配音需 JAST SOUND 外设，不能理解为普通机器上自带完整语音。

CREATIVE PROFILE

作品怎样形成自己的风格

从早期以校园人物关系为中心的冒险，到都市悬疑、科幻与 Windows 多品牌作品，JAST 的目录呈现出叙事题材和操作系统同时扩展的过程。以下划分是基于作品的编辑观察。

1985—1993

校园系列与调查冒险

《天使们的午后》系列从键盘输入转向菜单选择；后续作品也把寻人、学园怪事和演艺圈命案放入人物关系之中。系列外传、修正版与合集需要分层阅读。

编辑观察阅读依据 ↗
1994—1998

科幻、都市与品牌分支

DEEP 用多个人物视角呈现同一事件；Tiare 的目录则涵盖异能都市、魔法校园与恐怖调查，并出现含战斗的 RPG。不能仅凭美少女画面判断主要玩法。

编辑观察阅读依据 ↗
1998—2001

Windows 叙事与系列承接

早期 Purple 作品使用仿生人、前世记忆和生死主题；2001 年系列由 Purple software 承接。专题同时展示创作关联与每个版本的实际发行署名。
